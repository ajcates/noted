# Project Overview: noted

`noted` is a lightweight, mobile-optimized note editor designed for modern development workflows. It operates as a local web server launched directly from the command line, providing a Progressive Web Application (PWA) interface for managing and editing files within a specified directory.

## Core Mission
To provide a seamless, offline-capable editing experience that bridges the gap between local file systems and mobile accessibility.

## Key Features
- **CLI-Driven:** Launch the editor instantly for any directory using a simple command.
- **Progressive Web App (PWA):** Installable on mobile and desktop, working reliably offline.
- **Bidirectional Synchronization:** Real-time updates via WebSockets when online, with robust conflict resolution (diff-based) for offline changes.
- **File Management:** Full support for creating, renaming, and deleting files and folders.
- **Secure Access:** Optional password protection via configuration.
- **Modern UI:** Built with MDUI v2 for a clean, Material Design 3 compliant interface.

## Target Audience
Developers and power users who want to edit local notes or documentation from their mobile devices or tablets without relying on third-party cloud services.
